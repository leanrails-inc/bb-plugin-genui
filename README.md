# Moved: Generative UI for BB (leanrails-inc fork)

This repository is archived. The plugin now lives in [leanrails-inc/bb-plugins](https://github.com/leanrails-inc/bb-plugins), folder [`plugins/genui`](https://github.com/leanrails-inc/bb-plugins/tree/main/plugins/genui).

```sh
bb plugin install git:https://github.com/leanrails-inc/bb-plugins.git@main --plugin genui --yes
```

It is a modified fork of [ComicBit/bb-plugin-genui](https://github.com/ComicBit/bb-plugin-genui) (Apache-2.0, see [LICENSE](LICENSE)). The code here stays readable at its last commit; the branch `interaction-style` holds the single change meant for upstream.
